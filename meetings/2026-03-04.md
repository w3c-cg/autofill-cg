# Autofill Event Proposal
Presentation
Slides, Explainer, Recording

- Yoav: User goal accomplishments increase when using Autofill, but it can be hacky
  - major problem: Spec assumes that HTML forms are static, but real forms, especially address forms, are dynamic, which creates friction
  - "honeypot" fields are typically required for making autofill to work properly
  - Adds a refill function that site developers can use to notify the browser to request a refill the form with autofill data.
  - Chrome origin trial in 147
  - Can have issues with autofill extensions
    - sites cannot detect when users have an autofill extension installed.
    - extensions disable browser autofill but don't support the autofill event, even though feature detection passes.
  - solutions:
    - long-term: extensions should support the full API
    - short-term: extensions can disable feature detection (window.AutofillEvent = undefined)
    - alternatively, using the didPerformAutofill …
